# Codex execution plan: strengthen `paper1` experimental evidence

> Target branch: `ag/dev`  
> Target paper: `paper1/main.tex`  
> Scope: update `paper1` only. Do **not** import claims from other project documents unless the claim is revalidated from code/data used by `paper1`.

This document converts the paper review feedback into an executable plan for Codex. The goal is to substantially strengthen the empirical support for the current `paper1` theory: ACPC radius--margin certificate, local Gaussian sensitivity, and diagnostic-region validation for fixed JEPA world-model checkpoints under matched Gaussian observation noise.

The current paper is already theoretically stronger than before. The remaining weakness is experimental: the evidence chain is still too close to "closed-loop phenomenon + endpoint diagnostics + retrospective proxy overlay." The paper should be upgraded toward:

```text
full-sweep diagnostic dynamics
+ held-out diagnostic-region validation
+ theorem-aligned fixed-pool tail/top-1 audit
+ Gaussian sensitivity mechanism audit
+ stronger selective/action-conditioned discriminability checks
```

The work below is organized as must-do, strong-add, and optional-add tasks. Codex should implement the highest-priority executable subset first, then update the paper text only to match completed results.

---

## 0. Non-negotiable rules

1. **Do not fabricate results.** If raw logs are unavailable, either recompute them or write a clearly labeled `MISSING_DATA` note and downgrade the claim.
2. **Do not turn the paper into a method-comparison paper.** Avoid adding DrQ/Dreamer/TD-MPC baselines unless they already exist in the repo with comparable training budgets. The current contribution is diagnostic, not SOTA control.
3. **Do not overclaim the certificate.** The theorem is fixed-pool and matched-perturbation only. If using q90/q50 summaries, call the result a proxy audit, not a calibrated probability certificate.
4. **Do not use closed-loop scores to tune diagnostic thresholds on the same held-out units.** For prospective/held-out validation, freeze diagnostic gates on calibration units first, then evaluate on held-out units.
5. **Keep `paper1/main.tex` internally consistent.** Any new figure/table must be generated by reproducible scripts and referenced from the text. Any failed or mixed result must be stated honestly.
6. **Prefer training-free diagnostics first.** Most requested evidence can be computed from checkpoints/logged histories without retraining.
7. **Use current `paper1/main.tex` as the paper source of truth.** The doc below is a plan; the paper text must reflect actual computed outputs.

## 1. Current weakness to fix

### What is currently strong

The current `paper1/main.tex` already contains:

- ACPC definition as same-state clean/noisy action-conditioned rollout agreement plus different-state discriminability.
- ATR as upper-tail same-state predictive radius diagnostic.
- SMPR as task-grounded anti-collapse margin pass diagnostic.

- Radius--margin proxy overlay and top-1 agreement appendix audit at base/onset/endpoint.
- Bounded blur/resize unseen-stressor check.

### What remains weak

Reviewers can still object that:

1. ATR/SMPR are mostly shown at endpoints, not across the full checkpoint sweep.
2. The diagnostic-region validation is closer to retrospective alignment than true held-out prediction.
3. The radius--margin theorem speaks about tails and fixed-pool events, but the experiment mostly uses q50/q90 proxy summaries.
4. The Gaussian sensitivity theory is not empirically validated by Jacobian or local-noise-scaling evidence.
5. SMPR proxy labels may be too weak, especially for PushT and Cube.
6. The link between fixed-pool candidate stability and the actual planner action is not empirically bridged.
7. Quantile/threshold choices are under-audited.

The must-do tasks below directly address these objections.

# Must-do task M2: held-out diagnostic-region validation

## Goal

Upgrade retrospective overlay into a held-out diagnostic validation. The key is that diagnostic thresholds/gates are chosen on calibration units and evaluated on held-out units.

## Core principle

Do **not** tune gates by looking at the held-out closed-loop recovery labels. Closed-loop labels are only used after the diagnostic prediction is frozen.

## Splits

Run two validation modes.

### Mode A: leave-one-training-seed-out

For each held-out training seed `s in {3072, 3073, 3074}`:

- Calibration units: other two training seeds, all tasks.
- Held-out units: seed `s`, all tasks.
- Learn/freeze a simple diagnostic gate on calibration only.
- Predict fragile/recovered/transition region on held-out rows.

### Mode B: leave-one-task-out

For each held-out task:

- Calibration units: other three tasks, all training seeds.
- Held-out units: held-out task, all training seeds.
- Freeze gate on calibration only.
- Evaluate onset boundary error and fragile/recovered separation.

## Diagnostic features

Use only diagnostic features, not closed-loop score, as gate inputs:

```text
normalized_ATR
SMPR
proxy_gap_normalized or proxy_gap_sign
Top1Agree
```

Suggested normalizations:

```text
normalized_ATR(task, seed, rho) = ATR(task, seed, rho) / max_rho_ATR(task, seed)
proxy_gap_sign = 1[proxy_gap > 0]
proxy_gap_scaled = proxy_gap / (abs(clean_margin_q50) + 2*abs(cost_drift_q90) + eps)
```

## Simple deterministic gate options

Start with low-complexity gates, not learned black-box classifiers.

Candidate gate:

```text
recovered_pred = (normalized_ATR <= tau_atr) AND (SMPR >= tau_smpr)
```

Stronger gate:

```text
recovered_pred = (normalized_ATR <= tau_atr)
                 AND (SMPR >= tau_smpr)
                 AND (proxy_gap > 0 OR Top1Agree >= tau_top1)
```

Threshold grid on calibration only:

```text
tau_atr in {0.05, 0.075, 0.10, 0.15, 0.20, 0.30}
tau_smpr in {0.80, 0.85, 0.90, 0.95}
tau_top1 in {0.80, 0.90, 0.95}
```

Objective on calibration:

```text
minimize onset boundary error first, then false early rate, then false late rate
```

If there is too little data for a stable threshold grid, use a predeclared heuristic gate:

```text
normalized_ATR <= 0.15 and SMPR >= 0.90
```

Then report it as a fixed heuristic diagnostic validation, not a learned predictor.

# Must-do task M3: theorem-aligned fixed-pool tail/top-1 audit

## Goal

Move from q50/q90 proxy-only evidence toward fixed-pool event evidence that directly matches the radius--margin theorem's intermediate condition.

Current paper already admits q90 with K=65 gives a vacuous union-bound if naively interpreted. The remedy is **not** to manufacture a probability certificate. The remedy is to report the actual fixed-pool sufficient event and observed top-1 flip/agreement over the full sweep.

## Key event

For each clean/noisy history and fixed candidate pool:

```text
max_cost_drift = max_j |C_clean(a_j) - C_noisy(a_j)|
clean_margin = C_clean(a_2) - C_clean(a_1)
cert_pass_pool = 1[max_cost_drift < clean_margin / 2]
top1_agree = 1[argmin_j C_clean(a_j) == argmin_j C_noisy(a_j)]
```

The event `cert_pass_pool = 1` is a deterministic sufficient condition for top-1 stability on the shared fixed candidate set. It is closer to the theorem than q50/q90 summaries.

# Strong-add task M4: local Gaussian sensitivity / Jacobian mechanism audit

## Goal

Empirically support the new local Gaussian sensitivity theory. The paper currently derives:

```text
E[R_sigma^2] approx sigma^2 || J_G J_E ||_F^2
```

Now add evidence that measured small-noise radius scales approximately with sigma^2 and that sensitivity decreases from fragile to recovered checkpoints.

## Minimal version: finite-difference sensitivity audit

If exact JVP through the full encoder--predictor is hard, start with finite differences.

For anchors `h` and action sequence `a`:

```text
R_sigma = d_H(G_a(E(h)), G_a(E(h + noise_sigma)))
finite_diff_slope = E[R_sigma^2] / sigma^2
```

Use small sigmas:

```text
sigma in {0.0025, 0.005, 0.01, 0.02}
```

Run on:

```text
base rho=0.00
recovery onset rho
endpoint rho=0.08
```

At minimum, use 1--2 representative tasks; preferred: all four tasks.

## Strong version: Hutchinson/JVP estimate

Estimate:

```text
S_comp = || J_{G_a}(E(o)) J_E(o) ||_F^2
```

Use Hutchinson trace estimator:

```text
E_v || A v ||^2, v ~ Rademacher or Gaussian
A = J_G J_E
```

Implementation hint in PyTorch:

```python
# pseudo-code
with torch.enable_grad():
    o = o.detach().requires_grad_(True)
    y = rollout_projection(encoder(o), actions)  # vectorized projected rollout
    v = torch.randn_like(o)
    _, jvp = torch.autograd.functional.jvp(lambda x: rollout_projection(encoder(x), actions), o, v)
    estimate = (jvp.flatten() ** 2).sum()
```

If `torch.func.jvp` is available, prefer it. If not, use finite differences as fallback.

## Optional decomposition

Also estimate:

```text
S_E = ||J_E||_F^2
S_G = ||J_G||_F^2
kappa = S_comp / (S_E * S_G + eps)
```

This can identify whether improvement comes from encoder contraction, rollout contraction, or alignment repair.

## Option B: action-distinct pass rate

For same clean state `s`, sample two action sequences `a_i`, `a_j` that produce different external futures or candidate costs:

```text
external_future_distance(Y^H(s,a_i), Y^H(s,a_j)) > m
```

Then require predicted rollout separation:

```text
d(Psi(G_{a_i}(E(h))), Psi(G_{a_j}(E(h)))) > same_state_noise_radius + delta_m
```

Define:

```text
ADPR = Action-Distinct Pass Rate
```

This directly supports the paper's claim that robustness is action-conditioned, not just encoder invariance.
