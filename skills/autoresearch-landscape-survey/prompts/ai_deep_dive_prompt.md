# AI Deep Dive Prompt

Write a detailed deep dive for one AutoResearch-related project.

Required sections:

1. Project identity: name, repo, paper, license, maturity.
2. What problem it solves.
3. Field/domain facets.
4. Starting point and primary outputs.
5. Workflow and pipeline mechanics.
6. Agent roles and role separation.
7. Execution depth: text, code, training, benchmark, wetlab.
8. Verification and accountability mechanisms.
9. Artifact and provenance model.
10. Human-in-the-loop design.
11. Security and reproducibility risks.
12. What is genuinely new compared with closest projects.
13. Gaps vs Accountable Research CI.
14. Architecture lessons for our own system.
15. Recommended registry facets.

Do not write only a summary. Quote or cite specific repo files, docs, schemas, scripts, stage definitions, prompts, tests, or artifact formats whenever possible.
